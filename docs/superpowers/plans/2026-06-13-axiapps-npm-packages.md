# Ship @axiapps Shared Packages to npm Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the fragile `file:`-path sharing of `@axiapps/*` packages with real published npm packages so axivale and axibridge production builds and CI pass without sibling checkouts or build-on-install. This fixes the two release-blocking failures: (1) the axibridge rollup error `getFightOutcome is not exported by computePlayerAggregation.ts` (bridge-metrics is CJS-only, so the `export *` shims can't expose named exports to rollup's static analysis), and (2) axivale `npm ci` failing because the `file:` bridge-metrics dep runs `prepare: tsc` with `tsc` not installed on a clean runner, plus the three sibling-checkout requirements in CI.

**Working directories:**
- `/var/home/mstephens/Documents/GitHub/axibridge` — bridge-metrics package (dual build)
- `/var/home/mstephens/Documents/GitHub/axiforge` — forge-render + gw2-data packages
- `/var/home/mstephens/Documents/GitHub/axivale` — consumer deps + CI workflows

**Architecture:**
- `@axiapps/bridge-metrics` → **dual ESM + CJS + d.ts** build via `tsup`. ESM (`dist/*.js`) satisfies rollup's static named-export analysis (fixes the build error) and node/worker ESM; CJS (`dist/*.cjs`) satisfies the `scripts/metrics-audit.mjs` `createRequire()` sandbox loader that pulls the `src/shared/*` shims (which re-export `@axiapps/bridge-metrics/<sub>`). One entry per subpath module so the per-metric shims resolve.
- `@axiapps/forge-render` → stays ESM source (`?raw` SVG imports come from the `gw2-class-icons` npm dep, NOT local files); only its `@axiapps/gw2-data` dep flips `file:` → `^0.1.2`.
- `@axiapps/gw2-data` → in-repo source has **diverged** from published 0.1.1 (engine + wiki files differ), so bump to `0.1.2` and republish.
- axibridge consumes bridge-metrics as its own **workspace** package (no dep-source change) — the dual build alone fixes its rollup build.
- axivale flips three `file:` deps + the `gw2-class-icons` devDep to published `^` versions, drops three sibling checkouts in CI, and simplifies `optimizeDeps`.

**Tech Stack:** TypeScript, tsup (dual ESM+CJS), npm scoped public packages, electron-vite/rollup, vitest/jest.
